# ASK HELP DDA en DDA SUPPORT – downloads

Hier staan de APK-bestanden voor Android:

- **ASK HELP DDA**: de app voor klanten, voor telefoon, tablet en Android TV.
- **DDA SUPPORT**: de app voor medewerkers.

## Nieuwste versies

- [ASK HELP DDA 0.11.0](https://github.com/Deus73/digital-dope-support-downloads/releases/download/v0.11.0/ASK-HELP-DDA-0.11.0.apk)
- [DDA SUPPORT 0.6.0](https://github.com/Deus73/digital-dope-support-downloads/releases/download/staff-v0.6.0/DDA-SUPPORT-0.6.0.apk)

Beide apps hebben onderaan **Apps**. Support kan APK's en Apple-configuratieprofielen
toevoegen via downloadlink of Google Drive-upload. Klanten kunnen downloaden en delen.
APK's zijn voor Android; `.mobileconfig` moet je openen op een Apple-apparaat.

- Download de nieuwste versie onder **Releases**.
- Deze repository bevat geen broncode.
- Open het APK-bestand op je toestel. Als Android vraagt om installeren uit onbekende bronnen, geef dan toestemming voor deze download.
